# SquareDeviant

宗教組織「Messiah」が開発した装置により、全人類の体が強制的に四角になってしまう事件が起きた世界を舞台にしたアクションゲームです。プレイヤーはこの事態を止めるため、研究所へと乗り込みます。
現在、Steamでのリリースを目指して個人開発中です。

## ・プレイアブルキャラクターとコアメカニクス
本作にはプレイスタイルの異なる2人のキャラクターが存在します。

### Rifleist
「ブロック崩し」の要素を戦闘システムに統合しています。
敵の攻撃や環境をブロックに見立てて破壊することで、敵への大ダメージやプレイヤーの体力回復といった明確なメリットを生み出し、戦闘を有利に進める戦略的なシステムとして成立させています。

### Sharp
「誰でも簡単に爽快にできる」ことを追求したパリィシステムを実装しています。
判定をプレイヤー有利に調整しつつ、成功時の専用エフェクト、カメラシェイク、サウンドを組み合わせることで、映画のようなスタイリッシュなアクション体験を実現しました。

## ・技術スタック
* **Engine:** Unity 6 (URP)
* **Language:** C#
* **Libraries:** UniTask, DOTween, Input System

## ・アーキテクチャとこだわりの実装

開発途中で設計の限界を感じ、拡張性とパフォーマンス向上のために**プロジェクト全体の大規模なリファクタリング**を行いました。

### 1. State Machine パターンを用いたAI制御
Sharp編の敵について、初期はEnumとif文で敵の行動を制御していましたが、State Machineパターンを用いて一から作り直しました。これにより、バグの発生箇所を限定し、Rifleist編、Sharp編で異なる敵の挙動を、親クラスの継承を用いて安全かつ容易に拡張できる堅牢な設計を実現しました。

本リポジトリのScriptsフォルダの`CommandoController.cs` / `CommandoStates.cs`で、ステートマシンを用いた実装例が示されています。
近接攻撃、射撃、特殊攻撃、必殺技など、最も複雑な行動パターンを持つボス敵（Commando）のAI制御スクリプトです。

### 2. メモリ・パフォーマンスの最適化 (UniTask & ObjectPool)
アクションゲームにおけるガベージコレクションスパイクを防ぐため、動的タスクの処理にUnityのCoroutineではなく `UniTask` を全面的に採用し、メモリのゴミを排出しないゼロアロケーションな非同期処理を実装しました。また、弾やエフェクトの生成には `ObjectPool` パターンを導入し、動的生成・破棄による負荷を極限まで抑えています。

### 3. データ駆動とインターフェースによる疎結合
体力や攻撃力などのパラメータを `ScriptableObject` でデータ化し、外部から動的に読み込める設計にしています。また、ダメージを受けるオブジェクトを `IDamageable` のようなインターフェースで定義し、プレイヤーと敵のベースステータスに継承させることで、コンポーネント間の疎結合を保っています。

### 4. UniTask と DOTween を活用したUI/UX制御
ゲームプレイだけでなく「手触り」や「世界観の没入感」にもこだわり、UniTaskとDOTweenを組み合わせて非同期のUIアニメーションを実装しました。
『BIOHAZARD RE:4』のようなスタイリッシュで単調にならないUI構成を目指し、コールバックのネストを避けた直感的なコードで、ロード画面やステージ遷移の演出を制御しています。
